## 4. 残り（未達・Q候補）

1. **ヘビーのゴールドの10倍（9.85倍、−1.5%）**：レアダンジョンの宝箱の倍率では変わらない。自動プレイが旅の商人が出るたびに必ずパーティを送り、往復でオンラインの探索の時間が減っているのが主な原因と見ている。今回はそのまま（ユーザー判断）。
2. **先に開けたダンジョンの踏破率（D-294、0〜14%）**：`unlockGold` では変わらない。段階ごとのダンジョンの強さの段差が大きいため。直すなら段差（ダンジョンの強さか段階の想定）の見直しが要る。
3. **3周目の必要経験値が2周目より小さい**（0.638 < 1.136）。1・2周目を据え置いたため。手応えとして気にならないかは未確認。
4. **途中の目安の抜け**：パーティ枠を一度に2つ増やすと「パーティ枠 → n」が1つ抜ける（自動プレイの記録。判定には影響なし）。
5. 判定の幅のうち決定にないもの（配分 ±5pt、商人 ±5pt、フレンド ±2pt、踏破率 ±10pt、所要秒 ±10%、道具の数 ±20%）は仮。
