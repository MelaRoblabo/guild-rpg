ただし古い墓地にも適用すると初期パーティの踏破率が9%に落ちるため、古い墓地は据え置きが必要。

## 3. 提案（Q-003 / Q-004）

1. **モンスターHP**：古い墓地は現行のまま、遺跡・塔・古城は基準HPを2.5倍。目安は「適正レベルで1戦闘3〜4ターン」。
2. **古い墓地の距離**：3 → 2。初回の所要時間を60秒以内に収める。
3. **罠**：K を 10 → 40、罠ダメージ率 15% → 20%。技巧と罠師の勘に意味を持たせる。
4. **フロア数**：7/9/11/13 のまま（所要時間は塔・古城で約1.5〜2.5分。序盤30〜90秒の目標とも整合）。
5. **要検討（仕様の追加が必要）**：4ダンジョンだけでは Lv20前後で挑戦先がなくなり、レベル上限30〜100・転生の目標が生まれない。ダンジョンに難易度段階（例：★1〜★5、基準値と最低宝箱ランクを段階ごとに上げる）を設けるか、ダンジョン数を増やすかを決める必要がある。
