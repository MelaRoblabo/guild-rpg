# 冒険者ギルドRPG（仮）新規プレイヤー テストプレイレポート

- セーブ：`out/playtest/newbie.json`（`new 1` で開始）
- 遊んだ時間：仮想 2:00:05
- 実行回数：CLI 起動 約110回（そのうち雇用・転生の引き直しはシェルのループで約150回 reroll）
- 最終状態：ギルドLv26、所持金 39,307G、所属12人、パーティ3つ、チケット561枚、水没神殿まで踏破（霧の大森林は解放のみ）

## 2. 判断の理由

- **最初は「解放」を追った**：`dungeons` で未解放が並んでいて、`hint` の難度と敵の目安を見て、撤退しない一番上の所を周回した。撤退が出たら1段下げて資金とレベルを稼いだ。
- **お金はパーティ枠を優先した**：`expansions` で「パーティ枠：1→2（罠の遺跡を踏破、3000G）」を見て、周回の効率が倍になると考えた。
- **Lv1の新人はトレーニングで底上げした**：`show` で「トレーニング1回 10G」と出ていたので、新人に使うのが安いと判断した。実際は回数ごとに高くなる（後述）。
- **装備は IL とレアリティだけで選んだ**：攻撃力などの数値が出ないので、「IL が高い」「レアリティが高い」「退魔の（アンデッド向け？）」くらいしか判断材料がなかった。
- **転生はLv20になった人から順に**：ミラを転生させたら、Lv15の時点で元の誰よりも強くなった。それで「転生は即やるべき」と分かって、残りもすぐ転生した。
- **引き直しは「前回か今回の良い方」を残す二択だと理解してから**、「今回 ≥ 前回なら引く／前回の方が良ければ確定」と決めて引いた。チケットが余っていたので、最後は目標値（主ステの加算が上限近く）が出るまで引いた。

## 3. 迷った点・分かりにくかった点

1. **「解錠技術が足りない」の意味**
   `status` に毎回「未開封の宝箱 4個（古い墓地×4（解錠技術が足りない））」と出るのに、`open dng_graveyard` で普通に全部開く。`help` には「expand … 解錠技術もここ」とあるが、`expansions` の一覧に解錠技術の項目が最後まで出てこなかった。何が足りなくて、何を買えば良いのか分からない。
2. **引き直しで良い結果が消える**
   `reroll` の説明（「今回の結果が前回になり、それより前は消える」）は読んでいたが、最初の雇用で合計95を「残した結果（prev）」にしたまま `reroll` を2回して、95を失った。表示の「残した結果」という言葉から「キープされ続ける」と誤解した。転生の `rb-reroll` でも同じ失敗をした（加算合計20を流した）。
3. **装備の性能が見えない**
   `warehouse` は「eq_39 ロングソード［アンコモン・IL2］ 枠:武器 売値…」だけ。攻撃力などの数値も、装備できる職業も出ない。`equip adv_13 eq_22` →「✗ この職業では装備できません」で初めて分かる（僧侶は「ローブ」不可、魔法使いは「法衣」不可）。
4. **装備・編成が探索中にロックされる**
   `repeat` を設定すると常に探索中になるので、装備を替えるたびに `repeat n off` → `wait` → `equip` → `go` → `repeat` の5手順が必要。
5. **装備中のアイテムを指定したときのエラー文**
   待機中のミーシャに、探索中のアルドが装備している eq_710 を付けようとした `equip adv_1060 eq_710` が「✗ 探索中は変更できません」になる。ミーシャは探索中ではないので混乱した。
6. **トレーニング費用の表示**
   `show` の「トレーニング1回 10G」を見て安いと思ったが、`train adv_336 max` は34回で16,580G。費用が回数ごとに上がることも、max が所持金をほぼ全部使うことも、実行前に分からなかった。`trainquote` の存在に気づいたのは後になってから。
7. **`max` の上限が人によって違う**
   ガロの `max` はLv5で止まり、ブランはLv10まで上がった。何が上限なのか説明がない。
8. **`party` の入れ替えの挙動**
   `party 2 2 adv_336` → `party 2 1 adv_336` とすると、ボルドが2番に押し出され、リンがパーティから外れた。何が起きたか表示されない。`roster` にも所属パーティが出ない。
9. **転生の表示**
   - 「新しい見た目：chr_f_ugl_phy_06」のように内部IDがそのまま出る。ガロ（男のドワーフ）が転生後に `chr_f_…`（女性？）になったように見えた。
   - 「腕力18(+5/7)…HP65(+16/29) ／ 加算合計 5」：加算合計にHPが含まれないことは数字から推測するしかない。固定の引き継ぎ分（基礎値のうち加算前の部分）がどう決まるかの説明もない。
10. **ギルドLvの必要経験値**
    Lv1〜10は「/109」、Lv11からは「/78」に減り、Lv21からは「/174」。途中で必要量が減る理由が分からない。
11. **素材の使い道が分からない**
    騎士の紋章×265、潮の真珠×55、古代の歯車×77 などが貯まる一方で、使い道がどこにも書かれていない。

## 4. 退屈だった点・作業に感じた点

- **装備の付け替え**：宝箱を数十個まとめて開けるとエピックが4〜5個出る。誰に何を付けるかを、性能の数字なしで eq_ID を手で打って決めるのが一番の作業だった（3パーティ×4人×3枠）。
- **売却**：`sell` にIDを並べるしかないので、200個近くを手で売るのは無理。シェルで抜き出して一括売却した。`autosell` は「keep」だと修飾語つきが残るので、倉庫はすぐ埋まる。
- **引き直しの連打**：チケットが余りすぎて（最終561枚）、「目標が出るまで引く」だけの作業になる。1回ごとの重みがない。
- **中盤のログ**：2〜3パーティを周回させると、`wait 300` 1回で20行以上の帰還ログが流れる。毎回「踏破 宝箱N個 513G」とほぼ同じで、読まなくなった。

## 5. 嬉しかった瞬間・もう1回やりたくなった瞬間

- **最初の帰還が43秒**で、すぐに宝箱4個・全員レベルアップ・新ダンジョン解放。導入のテンポはとても良い。
- **0:37「★ 白銀のブラン が仲間に加わった！」**：突然のネームド加入にテンションが上がった。
- **転生で「魔力71(+26/27)」が出た瞬間**：上限ぎりぎりの数字が出て「当たった！」と感じた。転生直後のLv15で元の誰よりも強くなり、転生の価値が実感できた。
- **レジェンドの宝箱（★★★★★ 演出！）**：初めて見たときは嬉しかった。
- **雇用で合計151（腕力40 魔力36 俊敏39 技巧36）**が出たとき。

## 7. バグらしきもの・おかしな数値

1. **`train` で回数を省略すると CLI が固まる（無限ループ？）**（重要）
   - 再現：`new 1` → `go 1 dng_graveyard` → `repeat 1 dng_graveyard` → `wait 60` の直後（アルドは探索中）に `lune run tools/cli -- --save … train adv_1`
   - 結果：CPU 100% のまま20秒以上応答なし（timeout 124）。同じ状態で `train adv_1 1` は即「✗ 探索中は変更できません」が返る。
   - 後の別の状態では回数省略でも即答したので、条件つき（探索中？）かもしれない。
   - このほかに、標準入力で複数コマンドを流したときの無出力ハング（timeout 124、セーブは未更新）が2回あった。0:35:40 付近の `open dng_castle` …、`repeat 1 off` / `wait 20` / `equip …` / `rebirth adv_13` の並び。同じ状態のコピーで再試行すると再現しなかった。同時に他の負荷プロセスも動いていたので、環境要因の可能性もある。
2. **「解錠技術が足りない」と出ても開けられる**
   `status` の未開封表示に必ず付くが、`open` は成功する。`expansions` にも解錠技術が出てこない。
3. **トレーニング単価の表示**
   `show adv_48` で「トレーニング1回 10G」なのに、`trainquote adv_48 5` は「6回 620G」。初回の単価だけを出していて誤解を招く。
4. **待機中の人に付けようとしたときの誤ったエラー文**
   `equip <待機中の冒険者> <探索中の他人が装備中のeq>` →「✗ 探索中は変更できません」。
5. **転生で見た目IDがそのまま表示される／性別が変わる？**
   `rebirth adv_48` →「新しい見た目：chr_f_ugl_phy_06」（男性ドワーフのガロ）。`rebirth adv_1 keep`（見た目維持）でも「新しい見た目：chr_m_nor_phy_01」と出るので、維持されたのか判断できない。
6. **見た目維持ポーションの残数（要確認）**
   0:50時点で×1、1:12に1個入手、1:16に `rebirth adv_1 keep` で使用、終了時に×2。途中のレア宝箱ログをフィルタして見落とした可能性もあるが、消費されていない疑いがある。
7. **ギルドLvの必要経験値が途中で減る**
   Lv1〜10は「次まで x/109」、Lv11〜20は「x/78」、Lv21〜は「x/174」。

## 8. 改善提案（優先順）

1. **装備の性能表示と比較**：`warehouse` と `show` に攻撃力・防御などの数値と装備可能な職業を出す。さらに `equip` 前に差分（攻+12 など）を見せるか、`autoequip <adv|party>` を用意する。パーティが増えたときの作業の大半はこれで消える。
2. **探索中ロックの緩和**：装備変更を「次の出発から反映」で予約できるようにする。それが無理なら `recall` か「帰還したら停止」を用意する。`repeat` を使うたびに5手順かかるのが一番のストレス。
3. **引き直しUIの事故防止**：「残した結果（prev）」の横に「次に引くとこれは消えます」と出す。prev が cur より良いときは `reroll` に確認を入れる。あわせて、チケットの配布量（2時間で561枚）を見直し、1回の引き直しに重みを持たせる。
4. **お金の使い方の確認**：`train … max` の実行前に「X回・YG消費しますか」を出し、`show` の単価表示を「次の1回」の値にする。
5. **一括売却と素材の説明**：`sell all <最大レアリティ>`（装備中・ロック中は除く）を追加する。素材（騎士の紋章など）の用途を `items` に1行で出す。あわせて「解錠技術が足りない」表示と expansions の不整合を直す。
