決定：D-075（パーティ枠の解放条件・帰還間隔の調整）。ツール：`lune run tools/autoplay -- --hours 72 --seed 1`（72時間分を約1.5分）。
自動プレイの全記録：`docs/reports/M5_autoplay_72h_seed1.md`。

## 1. 作ったもの

- 拡張（パーティ枠・雇用候補枠・所属枠・倉庫）と BuyExpansion。費用と条件は `src/data/Expansions.luau`（仮）

- 自動プレイヤー（方針 greedy：雇用・装備更新・売却・拡張・転生・編成・行き先選びを自動で行う）

## 2. パーティ枠と帰還間隔（D-075）

ギルドレベル条件ではパーティが増えるほどギルドレベルも速く上がり、5枠目が14時間で開いて帰還間隔が9〜14秒まで縮んだ。
パーティ枠をダンジョンの踏破で開くようにし、強くなって速くなる幅を抑え（移動の短縮は最大20%）、難度3以降の所要時間を1.25倍にした。

## 4. 課題（要確認）

1. **ゴールドが余る**：72時間で約2.7億G。使い道は拡張と雇用費（300G）だけで、5枠目（300万G）も32時間時点で所持金の1/10以下。使い道（ゴールドの消費先）を増やすか、費用・収入を大きく変える必要がある（Q-022）。
2. **雇用のステータス上限**：ギルドLv1ごとに+1なので、Lv100で腕力 5〜119。一方、転生を重ねた冒険者は数百になるため、後半の雇用はほぼ意味がない（Q-023）。
3. **自動プレイの方針は1種類**：慎重型・収集型などの方針と、AIエージェントによるテストプレイは M6 で行う。
