# M4b チケット供給と転生スロットの再設計（2026-11-20）

決定：D-074。ツール：`lune run tools/sim/progression -- --write-guild`（ギルドレベル表を生成）。

## 1. 方針

- 「良いキャラ」＝転生スロットで上限比70%以上（4項目平均）。届くまでの期待回数は 1キャラ 転生1回目 約100回 → 8回目 約300回（仮）。
- 遊んで手に入るチケット＝4人が1回転生するのに必要な数の約50%（仮）。残りは追加で遊ぶか購入。
- 入手の中心はギルドのレベルアップ報酬。探索中のアイテムイベントからの入手は約1/10に減らした（ticket 0.60 → 0.06）。

## 4. 注意点（M5で確認）

- ギルド経験値は「帰還1回ごとの踏破ボーナス」があるため、短いダンジョンを回すほど早く貯まる。台本どおりの単純な遊び方では、1時間でギルドLv12・チケット244枚（計画は Lv10・193枚）。
- パーティを増やすとギルド経験値も増え、チケットも増える（育てる人数も増えるので、1人あたりはほぼ同じ見込み）。M5の自動プレイで確認する。
- 雇用のステータス上限はギルドレベル1ごとに+1（HP+3）。ギルドレベルが最大100になったため、上がり方が大きすぎないか M5 で確認する。
