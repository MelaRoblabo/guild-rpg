# M1b バランス再設計の報告（2026-11-20）

決定：D-067（数値調整）、D-068（ダンジョン追加・ダメージ式）、D-069（転生まで見据えたバランス・時間設計）、D-070（ギフト強化）。

## 1. 変更点

| 項目 | 変更 |
| --- | --- |
| ダンジョン | 4 → 12。tier 1〜12。モンスターは種族タグ・攻撃種別のみ（強さはダンジョンで決まる：D-003） |
| ダメージ式 | 攻撃力−防御 → 攻撃力²÷(攻撃力＋防御)。防御が攻撃力と同じなら半分。防御で急にダメージが消える段差をなくす |
| 装備 | アイテムレベル（入手ダンジョンの tier）を追加。1上がるごとに性能×1.3 |
| 移動 | 片道秒＝距離×10×clamp(ダンジョンの基準俊敏÷平均俊敏, 0.6, 1.4)。高難度ほど距離が長い |
| 罠 | K=40、ダメージは最大HP×20%（罠の遺跡・地下大迷宮は30%）。罠レベルは想定段階の技巧から自動決定 |
| ギフト | 俊足 +25%、退魔の才 +30%、頑健 +25%、道案内 ×0.7、罠師の勘 技巧×3、大食らい +25%、幸運 30%/人（上限60%）。個体補正の上限 +50% |
| 成長値 | 変更なし（D-043, D-044） |

## 3. 編成とギフトの効果（想定段階）

| ダンジョン | バランス | 物理偏重 | 魔法偏重 | 回復なし | ギフト持ち |
| --- | --- | --- | --- | --- | --- |
| 騎士の古城（物理防御が硬い） | 60% | **1%** | 85% | 79% | 75% |
| 鋼鉄の要塞（物理防御が硬い） | 60% | **3%** | 81% | 70% | 76% |
| 天空の玉座（長い・竜） | 60% | 3% | 71% | **31%** | 78% |
| 呪われた修道院（アンデッド多） | 68% | 57% | 71% | 65% | **90%** |

- ダンジョンの特徴に合わせて編成を変える意味が出た（企画書§14 検証項目2・3、D-049）。
- ギフト持ちは踏破率 +15〜20ポイント、宝箱数 約+40%。アンデッドの多い修道院では退魔の才で +22ポイント。

## 4. 残った課題（M6で扱う）

- 魔法偏重が多くのダンジョンでバランス編成より強い（盗賊の攻撃力が低いため）。探索系の価値（罠・クリティカル）をもう少し上げるか検討。
- 罠による全滅はまれ（1%未満）。罠は「HPを削る」役割に留まっている。
- 経験値は「次の段階の手前のレベルで5回の探索で1レベル」に合わせた。初転生までの時間は M5 の自動プレイで測る。
- ゴールドは tier ごとに1.45倍の仮置き。経済（拡張費用）との整合は M5。
