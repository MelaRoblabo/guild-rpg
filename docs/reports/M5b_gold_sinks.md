## 3. 調整の経緯

1. 1回目：解錠技術のレジェンド（500万G・ギルドLv50）が高すぎて買えず、開けられない宝箱が1万個以上溜まり収入が半減。
2. 保管が上限のとき出発を止めると、収入が止まって解錠技術も買えず**詰む**ことが分かった → D-083（出発は止めず、入りきらない宝箱を持ち帰れない）。
3. レジェンドの解錠を100万G・ギルドLv40に変更。

## 4. 課題（要確認・M6で調整）

1. **4.5〜9.7時間に宝箱の保管が満杯**（500個。開けられないレジェンドの宝箱）になり、その間の宝箱を持ち帰れず、4回目の転生が計画より約1.7時間遅れる。解錠レジェンドの費用・条件をもう少し下げるか、未開封の宝箱を売れる・捨てられるようにする（Q-024）。
2. 5パーティ時の帰還間隔は22〜27秒（目標30秒）。天空の玉座を回すようになれば伸びる。
3. トレーニングの費用・効果、派遣費、転生費用は仮。後半はトレーニングが最大の支出で、転生周回の短縮にも効いている（6・7回目の転生が計画より早い）。
4. 自動プレイを2本同時に走らせたとき、1本が30分止まった（単独では92秒で終わり再現せず）。M6 で再発すれば調べる。
