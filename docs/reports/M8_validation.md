## 3. 動きの確認と、見つけて直したもの

### 3.1 ログインの流れ（S-01 → カットイン → カレンダー）

留守の時間を作るため、プレイヤーを切断して保存を待ち、DataStore の記録の `lastAdvancedAt`・`lastSavedAt` を2時間前へずらし、休息ボーナスを 3600 秒に下げ、ログインボーナスの最後の受け取り日を1日前にして、入り直した。

見つけた問題と直したこと：

1. **まとめを出す条件が仕様と違っていた。** 11章 S-01（D-208 ④）は「留守番が動いた・休息ボーナスがたまった・受け取り箱に届いた、のどれかがあれば出す」だが、実装は帰還・ギルドLv・解放のときだけだった。休息ボーナスがたまったか（要約の `lastSavedAt` から今までの留守 × `restBonusRate`、上限まで：06章 §13 と同じ式）と、受け取り箱に届いたもの（`inboxUid` を持つ出来事）も条件に足した（`LoginFlow.restGained`、テスト2件）。「ログインボーナスだけならまとめを出さない」としていたテストは D-208 ④ と食い違っていたので、仕様どおりに書き直した。
2. **留守の出来事が0件だと、流れが始まらなかった。** 出来事が0件のときは `Session.events` が鳴らないため。ログインのたびに必ず鳴る `Session.loaded` を足し、ログインの出来事を `Session.loadEvents` に覚えておくようにした（待ち受けを始める前に届いても拾う）。
3. **ログインボーナスは、ログインの知らせには入らない。** ログインボーナスは留守の計算ではなく、ログイン直後の最初のオンラインの時間経過で届く（D-155、`Game` の advanceOnline）。そのため、ログインのあとに届く `LoginBonus` も受け取り、流れの途中なら最後につなぎ、そうでなければ画面が空いたときにカレンダーを出すようにした。

4. **ログインボーナスがまとめより先に届くと、まとめとカレンダーが2枚同時に開いた。** 要約がそろうのを待つ間に `LoginBonus` が届くと、別にカレンダーを開いていたため。まとめを出す前に届いたログインボーナスは、まとめの後ろにつなぐようにした。届く順番（ログインボーナスが先、ログインの知らせが後）を仮に再現し、まとめ1枚 → 次へ → カレンダーの順になることを確かめた。

直したあと：入り直すと、まとめ（パーティ1は留守の間に出ていない「⌂ !」、月は半分までたまる、受け取り箱5件）→ 次へ → カレンダー（4日目）の順に出た。ログインボーナスのない入り直しでは、まとめだけ出て閉じた（休息ボーナスがたまったため、D-208 ④ どおり）。

### 3.2 帰還のトースト

パーティ1を古い墓地へ出し（36秒）、オンラインのまま帰るのを待った。帰った瞬間に上の真ん中にトーストが出た（◀1・宝箱 +2・XP ×2・Go）。

見つけた問題：休息ボーナスの月（☾）と、Go の U ターンの印（↺）が Roblox の書体で出ず豆腐になっていた。月は 🌙 に、Go はパーティの面の Go と同じ ▶ にした。あわせて確かめた記号：☀ と ☠ は出る、☾ ↺ ⟳ は出ない。

### 3.3 出発の面（レアダンジョン）

レアダンジョンの時間帯に、マップの印（宝石と残り時間）を押して出発の面を開いた。強さの番号に ✓、★の宝箱 ×1.5、選んだパーティの4人と罠の棒、パーティの札、Go が出た。Go でパーティ1が出発し、印の下に「♟1 ✓」が付いた。

### 3.4 出発の面（レイド）

レイドの時間帯にプレイを始め、マップの印（稲妻と残り時間）でエラーが出ないこと（seed で落ちる不具合を直した後の実機）を確かめた。印から出発の面を開くと、ボスの HP の棒に、パーティ1のダメージの見込みが薄く重なって出た（HP はサーバーへの問い合わせ `Query` で取得）。Go でパーティ1が参加し、印の下に「♟1 ✓」が付いた。

### 3.5 S-44 見た目の変更

テスト用セーブに見た目変更ポーションを1個足し、`ChangeAppearance` のあと S-44 を開いた。新しい姿が左に大きく、前の姿が右の面に、Cancel と Nice が出た。前の見た目に戻して終えた。

## 5. 初回の誘導とボタンの語（D-244・D-245）

2人のテストで、初めて遊ぶ人にはパーティの出し方すら分からないことが分かった（ユーザーの確認）。アイコンだけで語を出さない作り（D-218）は、11章 §5.1 の初回の案内（D-123・D-124）があって成り立つ前提だったが、M8 でまだ作っていなかった。そこで D-244（誘導と出発までの道）と D-245（ボタンに語を添える）を決めて作った。見本は Guild UI の canvas（Guide2Party〜Guide5Equip・Icons）。

### 5.1 初回の誘導（D-244 ①）

- 「今やること」を1つだけ琥珀の輪で光らせ、指（画像がそろうまでは絵文字 👆／👇）で示す。ほかの所は暗くしない。段は 馬車 → パーティの面の Go → 帰還のあとの宝箱ボタン → 宝箱の一覧の Open All → 明かす画面・結果の Equip。
- 済んだ段の数は `SetGuideStep` でサーバーに保存する（戻らない。`settings.guideStep`、要約の `guideStep`）。保存がなく一度でも帰還したセーブ（誘導の前から遊んでいる人）は全部済んだ扱い。
- 後の段が先に済んだら前の段も済んだ扱い（マップから直接出発したときなど）。最初の開封で Equip が出ないときは、結果の画面で誘導を終える。
- マップの馬車を押すとパーティの面を開く（D-212。誘導の1段目）。

Studio の Player1（一度も出発していない状態から）で、馬車 → Go → 帰還 → 宝箱ボタン → Open All → 結果で終わる（`guideStep` 5）までを確かめた。

見つけて直したもの：

1. 輪をボタンの上に重ねると押せなくなった → 輪をボタンの後ろ（ZIndex 0）に置き、一回り大きくして縁だけ見せた。
2. ログインのまとめの下で、メイン画面の馬車が光っていた → 重ねた画面があるときは光らせない。
3. 帰還のトーストが右上の Quests に重なった → トーストを左寄りへ動かした。
4. Go・Open All の段の途中で面を閉じると、次に押す所が光らなくなった → その段の間はメイン画面の馬車・宝箱ボタンを光らせ続ける（直したあとの Studio での確認は未）。

### 5.2 出発までの道（D-244 ②③）

### 5.3 ボタンの語（D-245）

置ける広さのあるボタンはアイコン＋短い英語にし、小さくて分かりにくいボタン（下メニュー・右上・タブ・道具・並べ替え）は大きさを変えて語を入れた。語は `src/client/ui/Words` にまとめ、同じ操作には同じ語を使う。小さいボタンの語は 21px。語なしは閉じる×と、物そのものを触るもの（ダンジョン・馬車・カード・札）だけ。

誘導の確認で通った画面（メイン・パーティの面・宝箱の一覧・明かす画面・結果）で、語が欠けずに収まっていることを見た。そのほかの画面と iPhone 11 の大きさは、次のテストで見る。

## 9. 初見プレイの洗い出し（2026-11-25）

13歳・アメリカ在住・シミュレーションゲーム好き・Roblox 歴は長いが事前知識なし、サムネイルで RPG とシミュレーションの感じを受けて何となく始めた、という人の目で、空のセーブから約15分遊んだ（ログイン → 出発 → 帰還 → 宝箱 → 受け取り箱 → 雇用 → 冒険者 → 編成 → クエスト）。テスト用セーブは使わず、保存の鍵の頭を一時的に変えて始めた（クラウドの DataStore に試しの鍵が1件残っている）。

初回の誘導（§5.1）は効き、出発から最初の開封までは迷わなかった。問題は誘導のあと。

### 9.1 重い（やめる理由になる）

1. **探索中に何も起きていないように見える。** 馬車はダンジョンの上で止まり、残り時間はどこにも出ない。パーティの面の「48 Ghost」と黄色の棒が、敵の HP なのか味方が危ないのか分からない。シミュレーション好きが一番見たい「働いている感じ」がない。
2. **最初の宝箱が地味。** G +45 と ⌂ +1 だけで装備が出ず、誘導の Equip の段が出ないまま黙って終わった。結果の画面もほぼ空。
3. **誘導のあとに目標がない。** 13,923 G を持っていても、次にやることも使い道も示されない。いちばん分かるのはクエストの面だが、そこへ導くものがない。
4. **雇っても何も変わらない。** 採用のあとの「Party」はメイン画面に戻るだけ。パーティは4人で満員なので、雇った人はどこにも入らない。編成の面の下に名前のない小さなコマと「○」が出るが、それが雇った人だと分からない。
5. **サムネイルとの落差。** マップは茶色の地面に I・II・III の丸だけで、名前も絵もない。「Bust-up (placeholder)」「Receptionist (placeholder)」がそのまま出る（絵がそろうまでの仮）。

### 9.2 中くらい（迷う・誤解する）

6. 最初に出るのがログインのカレンダー。「12,000 G」とあるのに所持金は 500 のままで、受け取り箱に入っている。受け取れたのか分からない。
7. 宝箱ボタンが、0個でも金色で「!」付き（中身は受け取り箱）。誘導が指す馬車より目を引く。
8. 馬車が「1」と書いた小さな四角で、馬車に見えない（ダンジョン I を直接押しても出発の面が開くので詰まりはしない）。
9. 出発の面の記号（⚔〜◈ の棒・⚠ 1・○□○□ の並び）の意味が分からない。Go は押せる。
10. 待機中のパーティの面に、Go の行き先が出ない。
11. 求人票の面は、票を押すまで Hire が出ない。能力の「?」・▲▲・3枚目の「?」の意味が分からない。面接で、その人が良いのか比べる手がかりがない（Thief なのに MAG が一番高い）。
12. 同じアイコンが別の意味で使われている：⚔＝Warrior と Thief、◈＝Mage と Priest、⌂＝Guild・Home・待機中・宝箱の +1、コマ＝Friends・Adventurers・パーティ、▣＝宝箱とクエストの報酬（D-244 ④ で描き分ける予定）。
13. パーティが Lv2 になったことに、冒険者の一覧を開くまで気づかない。
14. マップイベントの印が、右端で切れて Friends の後ろに隠れる（§7 の仮の場所）。

### 9.3 軽い

15. 受け取り箱の出どころの印（▦・◉）が何の報酬か分からない。宝箱の一覧の右半分が空の枠。
16. クエストの週の欄に、初めての人には分からない「Rebirth」がある。▣★ 0/3 の意味が分からない。
17. 受け取り箱で チケット +5 を受け取ったのに、ギルドの旗は ×3。別の種類なら見分けが付かない（要確認）。

### 9.4 このプレイで見られなかったもの

- Equip が光る場面（最初の宝箱で装備が出なかった）。
