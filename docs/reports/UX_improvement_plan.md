# 初プレイの改善案（2026-11-25）

ペルソナ Mia（12歳・フィリピン・スマホの放置ゲーム好き）の初プレイと、ユーザー自身が「新しく手に入れた冒険者をどうやってパーティに入れるか分からなかった」ことから、3つの課題の改善案をまとめる。

- 課題1：雇う → 入れる → 装備する の流れがつながっていない
- 課題2：宝箱の楽しさが出ていない（開封の演出がない、装備の絵が結果に出ない）
- 課題3：記号だけの所で「これ何？」が多い

2026-11-26：§5 の答えを受けて、決定ログに D-264〜D-269 を起票した（§5 の末尾）。実装の順番は §6。

---

## 0. 解き方の順番

テキスト依存を減らす目標（D-148・D-218 ①③・D-245 の一部）はやめ、必要な所には文字を入れる。ただし、文字を足す前に、次の順で解けないかを先に考える。

1. **導線を短くする**：やりたいことの入口を、やりたくなった場所に置く。迷う分かれ道を消す。
2. **形と配置で伝える**：押せるものは押せる形（スイッチはスイッチ、開くものは ▼）。関係するものは隣に置く。
3. **動きで見せる**（トランジション・演出）：物が「どこからどこへ行ったか」を飛ばして見せる。変わった数字は動かす。
4. **最後に文字**：次の4つには必ず文字を入れる。
   - 画面のタイトル（1〜3語）
   - ボタン（アイコン＋動詞が先の語。例 Equip to Aldo）
   - 押せない理由（灰色のボタンも押せる。押すと一言の吹き出しが2秒）
   - 意味が1つに決まらない数字（ATK 9・Back in 1:05 など）

文字の量の上限：ボタンは3語まで、吹き出しは1行・12語まで。入りきらないときは語を縮めず、幅を広げるか2行にする。Guild UI の README と icons-and-words に書く。

各案の頭の印：【導線】【形】【動き】【文字】

## 1. 雇う → 入れる → 装備する

### 1.1 詰まりの原因（5つ）

1. 採用の画面の「Party」は、パーティが出かけていると黙ってメイン画面に戻る。
2. 編成の面に控えの列が出ていない。メンバーを押して初めて出る。控えのコマは名前だけで顔がない。
3. 入れ替えの操作（メンバーを押す → 控えを押す）を、どこにも見せていない。
4. 雇った人は装備なしで来る。入れ替えても装備は元の人に付いたまま。Auto Equip は灰色で理由が出ない。
5. 冒険者の詳細・倉庫から「パーティに入れる」「この装備を付ける」入口がない。

### 1.2 流れを作り直す

**採用の直後（雇った人が「控えに入った」ことを動きで見せる）**

- 【動き】HIRED のハンコのあと、雇った人のカードが縮んで飛び、画面の下からせり上がる控えの列に着地して光る。「この人は控えに入った」を一目で分からせる。
- 【導線】金のボタンは「Add to Party」。
  - 待機中のパーティがあれば、そのまま編成の面になる。カードが着地した控えの列が、編成の面の控えの列になる（画面が切り替わらず、つながって見える）。
  - 全員が出かけ中なら、カードはマップのギルドの建物へ飛び込む。建物の上に雇った人の顔と NEW の札が付く。パーティが帰ってギルドに着いたら、馬車から「!」が出て、指の誘導で「馬車 → Edit Party → NEW の人」を一度だけ案内する。
  - 「予約の入れ替え」（出かけ中に決め、帰ったら入れ替わる）は core の変更が大きいので、今回は入れない（§5 の要確認）。

**編成の面（タイトル「Edit Party」）**

- 【形】上に隊列の4枠、下に控えの列を常に出す。控えのカードは顔の絵・名前・Lv・職業のアイコン。新しく来た人は先頭に NEW。
- 【動き】入れ替えはドラッグとタップの両方にする。
  - ドラッグ：控えのカードを持ち上げると、隊列の4枠が小さく揺れて「ここに落とせる」を示す。落とすと2人が入れ替わる動き（出る人は控えへ、入る人は枠へ滑る）。
  - タップ：メンバーを押すと、控えの列がふわっと持ち上がり、控えのカードが脈打つ。控えを押すと同じ入れ替えの動き。
- 【文字】初回だけ、指の誘導に1行「Drag a reserve onto a member」を添える。
- 【導線】入れ替えで入った人の装備に空きがあれば、Auto Equip を自動で行う。倉庫から装備のアイコンがその人の枠へ飛んで収まり、能力の数字が上がる（取り消しは編成の面の Undo）。Auto Equip のボタンは残す。付けられる物がないときも押せて、押すと「No better gear in Warehouse」と出す。
- 【形】出かけ中のパーティの編成ボタンは、馬車が出ていく形の灰色にする。押すと帰るまでの残りの輪と「Back in 0:42」。

**雇ったときの装備**

- 【導線】雇った人に、職業に合ったコモンの武器・防具・補助を持たせて来させる（最初の4人と同じ扱い。マスターデータに職業ごとの初期装備の表を置き、core で付ける）。入れた直後に倒れる詰まりがなくなる。

**ほかの入口**

- 【導線】冒険者の詳細：控えの人に「Add to Party」。押すと編成の面が、その人を持ち上げた状態で開く。
- 【導線】倉庫の装備の詳細：「Equip」。付けられる人の顔が並び、それぞれに「+4」などの差が出る。選ぶと装備がその人の顔へ飛ぶ。
- 【形】メイン画面のギルドの建物を「控えの待機所」にする。控えの人数の札を付け、押すと冒険者の一覧が開く。

**語をそろえる**

- 【文字】パーティの面の「Menu」、編成の面、採用後のボタンが同じ画面を指しているので、「Edit Party」にそろえる。

## 2. 宝箱

### 2.1 帰還から開封まで（つながりを動きで見せる）

- 【動き】馬車がギルドに着くと、宝箱が1つずつ馬車から飛び出して、右下の宝箱ボタンに吸い込まれる。ボタンの数字が1つずつ弾んで増える（D-214 ⑨で決めて、まだ作っていない動き）。帰還の知らせを見逃しても、ボタンが増えたことが分かる。
- 【形】宝箱の一覧の各山は、文字の行ではなく、その山で一番良いレアリティの箱の絵を積み上げた形にする。数は箱の上の札。

### 2.2 開封の演出（必ず1回）

- 【動き】1回の開封につき、必ず1箱は演出する。開けた中で一番良い箱を、そのレアリティの箱の絵で画面の中央に出す。
  1. 箱が飛んできて揺れる
  2. ふたが開く（閉じた箱 → 開いた箱の絵に切り替え）
  3. 品の絵が飛び出して回り、表になる。枠の色がレアリティの色、下に名前とレアリティの語（Rare など）
- 長さは3秒以内。触ると早送り、長押しで飛ばす。語付きの「Skip」も置く（D-218 ④の「Skip ボタンなし」を置き換え）。
- 2箱目以降は今の短い流れでまとめて開ける。
- 最初の1回は、設定にかかわらずフルの演出。
- 設定の「Chest opening」は演出の長さの切り替えにし、オフでも最良の1箱だけは短い版（1秒）を出す。
- 本番の演出の語彙（先読み・予告など：D-140〜D-147）は M8-FX。ここで決めるのは「必ず1箱」と「品の絵が飛び出す」の最低限。

### 2.3 開けた品の行き先を動きで見せる

- 【動き】まとめて開けた品は、それぞれの行き先へ飛ぶ。
  - 強くなる装備：画面の上の冒険者の顔の横へ
  - それ以外の装備：倉庫の建物のアイコンへ
  - 自動売却：コインに変わって、右上の所持金に吸い込まれる（所持金がカウントアップ）
- これで「Auto-sold 1」の意味が動きで分かる。下の集計は「Gold +127」「Auto-sold 1」「To Warehouse +3」と語を付けて残す。
- 初めて自動売却が起きたときだけ、所持金の横に「Auto Sell is ON」の吹き出し。

### 2.4 結果の画面（品が主役）

- 【形】カードの読む順を「品 → 差 → 誰に」に組み替える。
  - 品の大きな絵、名前、レアリティの語、枠の語（Armor など）
  - 「DEF 3 → 9（+6）」
  - 小さな顔と「Equip to Aldo」
- 【動き】Equip を押すと、品の絵が冒険者の顔へ飛んで吸い込まれ、能力の数字がカウントアップする（今は棒が変わらず、強くなったことが見えない）。
- 【導線】結果を閉じたらマップへ戻る（今は空の宝箱の一覧に戻り、× がもう一度要る）。宝箱が残っているときだけ一覧へ戻る。

### 2.5 倉庫

- 【形】詳細の大きな枠に装備の絵を出す（今は剣の記号）。

## 4. 共通で作る動きの部品

同じ動きを画面ごとに作らないよう、client に部品として作る（M8-FX の演出エンジン D-147 とは別の、UI の小さな動き）。

| 部品 | 使う所 |
|---|---|
| 飛ばす（A から B へ、物のアイコンが弧を描いて飛ぶ） | 採用 → 控え、宝箱 → ボタン、品 → 顔・倉庫・所持金、Auto Equip |
| 数字のカウントアップ＋「+N」の浮き文字 | 所持金、能力、トレーニング、Equip |
| 脈打つ（押せる・落とせるの合図） | 控えのカード、隊列の枠、選べるダンジョン |
| ハンコ（Hired・Closed など） | 採用、マップイベントの締め切り |
| 理由の吹き出し（灰色のボタンを押したとき2秒） | Go、Auto Equip、Add to Party など |

- 点滅は1秒3回まで（D-145）。「点滅を減らす」がオンなら、飛ばす・跳ねるは短く弱くする。
- 動きの長さは1つ0.3〜0.6秒。続けて操作したら、残りの動きは早送りする（待たせない：D-218 ④の考え方は残す）。

## 5. 決めたこと（2026-11-26）

- **予約の入れ替え**：入れない。全員が冒険中に Add to Party を押したとき・冒険中のパーティの Edit Party を押したときは、「Can't add to a party on an adventure」のアラートを出す（D-265）。
- **雇った人の初期装備**：職業に合ったコモン3点（武器・防具・補助）。表はマスターデータ（D-266）。
- **入れ替え時の Auto Equip**：確認なしで行い、編成の面の Undo で戻す（D-266）。
- **開封の演出**：1回の開封につき最良の1箱・3秒以内・初回はフル・設定 Chest opening がオフでも1秒の短い版（D-267）。
- **盾 7 と盾 6**：品の札（WarehouseCommon.values）が物理防御と魔法防御を足していた。札を分けて直した。
- **起票した決定**：D-264（文字の方針。D-148 を廃止、D-218 ①③を置き換え、D-245 を広げる）、D-265（雇用からパーティへの流れ。D-226 ③を置き換え）、D-266（初期装備と自動装備）、D-267（開封の演出。D-218 ④の Skip を置き換え）、D-268（宝箱の行き先と結果）、D-269（記号の補いと動きの部品）。

## 6. 進め方

1. **決定ログに起票する**（6件前後）。文字の方針、雇用からパーティへの流れ、雇った人の初期装備、開封の演出（必ず1箱）、結果の画面と品の行き先、記号の補い。INDEX.md・Guild UI（README・icons-and-words）・11章も合わせて直す。
2. **作る順**
   1. 動きの部品（§4）と、雇う → 入れる → 装備する（§1）
   2. 宝箱（§2）。開封の最低限の演出はこのとき作り、本番の語彙は M8-FX へ
   3. 記号の補い（§3）
3. **合格の線**：空のセーブで初見プレイをやり直し、次がすべてできれば合格。
   - 雇った人を、説明なしでパーティに入れて装備できる
   - 開封の演出を見て、出た装備の絵と名前が分かる
   - 「これ何？」が2件以下
